# Contributing to Tapify

Thanks for taking an interest in Tapify. The project is an early front-end starter, and clear, small contributions are the easiest to review.

## Before you start

- Search existing issues and pull requests so work is not duplicated.
- For a larger change, open an issue first and describe the problem it solves.
- Keep changes focused and avoid adding dependencies without a clear need.
- Do not add real personal information, tracking, or network calls to the demo.

## Local setup

```bash
npm install
npm run dev
```

## Pull request notes

- Describe what changed and why.
- Mention the pages affected.
- Include screenshots for visual changes and note the viewport size.
- Call out anything that remains a demo or needs a backend before it can work in production.

## Community

Be curious, kind, and specific. Assume good intent and help make the project welcoming to new contributors.
